# Anonas2638-Project1

## Project Overview

This project is a responsive personal website created using HTML5 and CSS3. The website demonstrates the use of semantic HTML, responsive design, Flexbox layouts, CSS styling, transitions, tables, and forms.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- GitHub
- GitHub Pages
- XAMPP
